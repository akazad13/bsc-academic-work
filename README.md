## 📌 Overview

This archival repository documents academic coursework, laboratory implementations, system assignments, and undergraduate thesis research completed during my **B.Sc. in Computer Science and Engineering (CSE)** degree at **Rajshahi University of Engineering & Technology (RUET)**.

### Key Highlights
- 🔬 **Undergraduate Thesis**: Research manuscripts, datasets, experimental models, and evaluation source code.
- 💻 **Laboratory Assignments**: Implementations spanning Data Structures, Algorithms, Object-Oriented Programming, Compiler Design, Database Systems, Computer Networks, and Operating Systems.
- 📜 **Historical Reference**: Clean, documented academic history preserving foundational computer science implementations.
